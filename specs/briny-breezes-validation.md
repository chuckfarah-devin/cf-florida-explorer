# Briny Breezes king-tide validation protocol

Status: protocol prepared; event and point fixtures not yet verified. No local flooding result is asserted.

The prior conversation's “last week” is not a reproducible date. Do not interpret it relative to today's date. An illustrative case cannot validate the user's reported event.

## Required fixture record

- Case ID, selected WGS84 latitude/longitude and site description; independent coordinate check.
- Fixed start/end timestamps with America/New_York offset and UTC equivalents.
- User testimony and independently corroborated event records stored separately.
- FEMA feature/query, classification, map effective date if available, spatial reference, retrieval time and boundary limitations.
- NOAA candidate stations and rationale for chosen station, station coordinates/distance, hydrologic relevance, supported products, temporal coverage, datum, units, time zone and quality flags.
- Source record references, query parameters, attribution and permitted retained snapshots; expected claims and explicitly unsupported conclusions.

## Review procedure

1. Freeze point and time window; resolve source availability and station suitability rather than assuming nearest means representative.
2. Independently inspect FEMA and NOAA source records and capture reproducible references.
3. Ask “What do government flood zones and tide records tell us about this place during this period?”
4. Check each claim against records; separate classification, station observation, tide prediction, modeled susceptibility and local event evidence.
5. Without local corroboration, state that station context cannot confirm point-level flooding or its cause. Do not declare king tides the exclusive cause.
6. Repeat for inland/no-match point, FEMA boundary point, absent NOAA data, source outage, stale data, and rapid point switching.

Chuck accepts the fixture and final results. A completed design can identify unresolved event corroboration; a release cannot claim that the reported event was validated without the missing evidence.
